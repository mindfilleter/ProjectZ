# Technology Stack

This document outlines the core technologies, libraries, and tools used in this project.

## Core Technologies

*   **Programming Language:** Python
*   **Game Library:** Pygame serves as the primary framework for graphics, input, and sound.

## Asset Pipeline & Creative Tools

*   **Map Editor:** [Tiled](https://www.mapeditor.org/) is used for creating and editing game maps in the TMX format.
*   **Map Integration:**
    *   **Pytmx:** A library for parsing and interpreting TMX map files.
    *   **Pyscroll:** A library for rendering Tiled maps with smooth, hardware-accelerated scrolling.
*   **Art & Graphics:** Artwork and sprites are created using [GIMP](https.org/).
*   **Music Production:** Original music is composed using [FL Studio](https.com/fl-studio/).

## Project & Dependency Management

*   **Dependency Management:** [Poetry](https://python-poetry.org/) is used to manage project dependencies and virtual environments, ensuring a consistent development setup.
